# 🏚️ Online Escape Room Game

## 📖 Overview

Online Escape Room is a browser-based puzzle game where players solve clues, collect keys, and escape through multiple rooms.

---

## 🎮 Features

- 🔐 Login & Register
- 👤 Player Profile
- ⏳ Countdown Timer
- ⭐ Score System
- 🎒 Inventory
- 💡 Hint System
- 🔦 Flashlight Effect
- ⏸ Pause Menu
- ⚙️ Settings Menu
- 🎵 Background Music
- 📚 3 Interactive Rooms
- 🏆 Leaderboard
- 📄 Completion Certificate
- 🎉 Winner Screen

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage
